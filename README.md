# EVO CORE

لوحة أولية باللغة العربية لإدارة أفكار ومشاريع تطوير التطبيقات.

## ما الموجود حالياً؟
- لوحة تحكم عربية متجاوبة مع الهاتف.
- إضافة المشاريع وعرضها وحذفها.
- حفظ المشاريع محلياً في المتصفح.
- تصدير نسخة احتياطية بصيغة JSON.
- مساعد تخطيط يحوّل فكرة التطبيق إلى خطوات بداية قابلة للنسخ.
- ملف PWA وService Worker لدعم التثبيت والعمل دون اتصال بعد أول زيارة.
- إعداد GitHub Actions للنشر التلقائي على GitHub Pages عند تحديث فرع `main`.

## النشر المجاني
1. افتح إعدادات المستودع ثم **Pages**.
2. ضمن **Build and deployment** اختر **GitHub Actions** كمصدر.
3. انتظر انتهاء مهمة **Deploy EVO CORE to GitHub Pages** من تبويب **Actions**.
4. سيظهر رابط الموقع في إعدادات Pages وفي نتيجة عملية النشر.

## ملاحظات مهمة
هذه نسخة واجهة أولية. لا يوجد حالياً اتصال بنموذج ذكاء اصطناعي أو قاعدة بيانات سحابية أو نظام حسابات. بيانات المشاريع محفوظة في متصفح الجهاز نفسه، وقد لا تظهر على جهاز آخر. لا تضع كلمات مرور أو معلومات حساسة فيها.

## الملفات
- `index.html`: الواجهة والمنطق الأساسي.
- `manifest.json`: إعدادات تطبيق الويب.
- `sw.js`: التخزين المؤقت ودعم العمل دون اتصال.
- `.github/workflows/pages.yml`: النشر التلقائي.
